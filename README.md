# 🏰 Tower Defence – фінальний проєкт на .NET
## 📖 Опис проекту
**Tower Defence** – це класична гра жанру tower defense, реалізована на платформі .NET (C#). Гравець будує оборонні вежі, щоб захистити свою базу від хвиль ворогів. Проєкт складається з модулів:
- 	**Game** – основна логіка гри та управління рівнями.
- 	**Logic** – механіка бою, рух ворогів, робота веж.
- 	**Menu** – інтерфейс користувача та навігація.
- 	**Program.cs** – точка входу в застосунок.
---
## ⚙️ Системні вимоги та сумісність
- 	ОС: Windows 10/11
- 		Фреймворк: .NET 9.0 (Core)
- 	Мова програмування: C#
- Сумісність: працює на будь-якому ПК з підтримкою .NET 9.0, мінімум 4 ГБ оперативної пам’яті.
- 	Графіка: базова підтримка Windows Forms/WPF (залежно від реалізації UI).

##  ❓ FAQ
- 	Чи можна грати на Linux/Mac?
Так, через .NET 9.0 з використанням кросплатформових бібліотек, але потрібні додаткові налаштування.
- 	Чи є багаторівневі карти?
Так, у папці *Game* можна додавати нові рівні.
- 	Чи можна додати власні вежі?
Так, розширивши клас у *Logic* .
